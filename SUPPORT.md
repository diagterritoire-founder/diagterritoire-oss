# Support DiagTerritoire

## Questions et problèmes

Les questions d'utilisation, problèmes reproductibles et propositions
d'amélioration peuvent être ouverts dans les Issues GitHub du dépôt.

Avant d'ouvrir une Issue, il est recommandé de vérifier qu'un sujet équivalent
n'existe pas déjà.

## Informations utiles

Pour faciliter l'analyse d'un problème, indiquer lorsque cela est pertinent :

- la version de DiagTerritoire utilisée ;
- l'environnement d'exécution ;
- la version de Node.js ;
- les étapes permettant de reproduire le problème ;
- le comportement attendu ;
- le comportement observé ;
- les messages d'erreur utiles.

Ne jamais publier de secret, mot de passe, jeton, clé d'API, chaîne de connexion
ou donnée confidentielle dans une Issue.

## Vulnérabilités de sécurité

Une vulnérabilité potentielle ne doit pas être signalée dans une Issue
publique.

Utiliser le canal de signalement privé décrit dans `SECURITY.md`.

## Versions

Le projet concentre prioritairement sa maintenance sur la version stable
publique la plus récente.

Les corrections ne sont pas nécessairement rétroportées vers les anciennes
versions.

## Niveau de service

DiagTerritoire est un projet Open Source en développement actif.

Aucun délai contractuel de réponse ou de correction n'est garanti par le dépôt
public.
